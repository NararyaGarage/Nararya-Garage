## 📋 Overview

Nararya Garage JKT48 Discord Bot adalah bot Discord komprehensif untuk komunitas penggemar JKT48 dan 48Group, menawarkan berbagai fitur untuk meningkatkan pengalaman komunitas Discord Anda. Bot ini dilengkapi dengan notifikasi realtime, pelacakan member, sistem ekonomi, permainan interaktif, dan banyak lagi.

## 📥 Instalasi

### Prasyarat
- Node.js v22.18.1 atau lebih baru
- NPM v10.0.0 atau lebih baru
- Token Bot Discord
- Akses Internet untuk web scraping

### Langkah-langkah
1. Clone repositori ini
```bash
git clone https://github.com/nararya-garage/nararya-garage-bot.git
cd nararya-garage-bot
```

2. Install dependensi
```bash
npm install
```

3. Salin `.env.example` ke `.env` dan isi dengan kredensial Anda
```bash
cp .env.example .env
```

4. Edit file konfigurasi di `config.js` sesuai kebutuhan

5. Jalankan bot
```bash
node index.js
```

## 🔧 Penggunaan

Bot ini menggunakan sistem Slash Commands Discord. Untuk melihat daftar perintah yang tersedia, ketik `/help` di server Anda.

### Kategori Perintah:
- `/info` - Informasi tentang bot dan JKT48
- `/member` - Informasi tentang member JKT48
- `/games` - Game interaktif JKT48
- `/moderation` - Perintah moderasi server
- `/notifications` - Pengaturan notifikasi
- `/tickets` - Sistem manajemen tiket
- `/utilities` - Berbagai alat utilitas
